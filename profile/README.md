# Till it Works

Independent software studio from Leichlingen, Germany — building small, focused products for AI-native and cloud-native work.

🌐 [till-it-works.de](https://till-it-works.de)

## Products

### [Korpus](https://korpus.cloud)
Your workflow source code and data. An MCP-first workspace where humans and AI agents share documents, collections and files — works with Claude, ChatGPT, Copilot and others. GDPR-compliant, hosted in Frankfurt.

### [CostPulse](https://costpulse.cloud)
Native iOS app for AWS cost monitoring. Push alerts on spend changes and AI-powered cost recommendations — your AWS bill in your pocket.
